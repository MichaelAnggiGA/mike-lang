## Featured Project — Mike

**Mike** is a programming language for mathematical computing that compiles
directly to native x86-64 machine code. Every part of it was built from scratch:
the lexer, the parser, the code generator, a standard library of sixteen modules,
a plotting system, and cross-platform support for Linux and FreeBSD.

```
start module; hello
    lib input/output
    func main()
        print "oke"
    end func
end modul
```

Mike is guided by a single principle — **depth over breadth**. Instead of trying
to become a general-purpose language, it commits fully to numerical and
scientific computation and aims to do that one thing well.

**Highlights**

- Native x86-64 compiler — no interpreter; source compiles straight to an ELF executable.
- Sixteen standard libraries spanning mathematics, statistics, linear algebra,
  calculus, finance, physics, quantum simulation, cryptography, and engineering.
- User-defined libraries — anyone can extend the language with their own modules.
- Plotting in the terminal (ASCII) with optional SVG export.
- Portable across x86-64 Unix systems (Linux and FreeBSD).
